# ATM Management System

A Java-based command-line ATM Management System that simulates basic ATM and banking operations. The application allows users to securely log in and perform common banking transactions through a simple terminal interface.

## Features

- Account number and PIN authentication
- Maximum 3 login attempts
- Check account balance
- Deposit money
- Withdraw money
- View mini transaction statement
- Change PIN
- Input validation
- Error handling
- Command-line interface
- Object-Oriented Programming concepts

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList / Collections
- Exception Handling
- Command-Line Interface

## Requirements

- Java Development Kit (JDK) 8 or later
- Command Prompt / Terminal
